    Any SelfStudys notes / revision-notes page. Example:
    …/cuet/mathematics/…/notes/3-matrices

    2

    Paste it above

    The resolver reads the page and extracts its embedded direct PDF pointer (sitepdfs/…) — the same one the viewer loads.

    FAQ

    Is it free? Do I need an account?

    Yes, free, no account. The site is static (GitHub Pages) plus a tiny resolver Worker on Cloudflare's free tier.

    Why does it need a "Worker"?

    Browsers block one website from reading another site's pages (CORS). The Worker fetches the SelfStudys page server-side and returns just the extracted PDF link as JSON. It never stores your links.

    Where does the PDF come from? Is it re-hosted?

    No re-hosting. The download button points directly at SelfStudys' own file URL (selfstudys.com/sitepdfs/…). StudyFetch only automates finding that link.

    It says "no PDF pointer found" — what now?

    Make sure the URL is a notes/document page (not a homepage or listing), that it loads without login, and try again. If SelfStudys changed their page markup, the resolver patterns may need an update — see README.

    Can I share a result?

    Yes — after resolving, your address bar contains ?url=…. Anyone opening that link gets the input prefilled — one click and they have the same result.
